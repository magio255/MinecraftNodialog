# Dialog Blocker

Dialog Blocker is a client-side Fabric mod for Minecraft 1.20.1 designed to prevent modern Dialog GUIs (introduced in Minecraft 1.21.6+) sent by servers when connecting via ViaFabric / ViaFabricPlus.

## Commands

- `/dialogblocker on` - Enables Dialog Blocker
- `/dialogblocker off` - Disables Dialog Blocker
- `/dialogblocker toggle` - Toggles Dialog Blocker state

## Build Instructions

To build the mod JAR, run:

```cmd
gradlew.bat build
```

The resulting JAR file will be located at `build/libs/dialogblocker-1.0.0.jar`.
